# 三层权限模型

> 你的平台 | 你的规则 | 你的所有权

Chaotools 采用三层权限模型，确保工具所有权始终在平台所有者手中。

## 三层架构

```
┌─────────────────────────────────────────────────────────────┐
│                        PUBLIC (公开)                          │
│                   所有访客都可以使用                           │
│                                                              │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                   COMMUNITY (社区)                     │   │
│  │           贡献者提交的工具，经审核后公开                │   │
│  │           贡献者有署名权，所有权归平台                   │   │
│  │                                                         │   │
│  │  ┌─────────────────────────────────────────────────┐  │   │
│  │  │              PRIVATE (私有)                      │  │   │
│  │  │         只有你能看到和使用的工具                   │  │   │
│  │  │         开发中/内部使用/付费工具                   │  │   │
│  │  └─────────────────────────────────────────────────┘  │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## 工具 Visibility

| 层级 | 值 | 说明 | 可见范围 |
|------|-----|------|---------|
| 私有 | `private` | 私有工具 | 仅 owner |
| 团队 | `team` | 团队工具 | owner + 团队成员 |
| 公开 | `public` | 公开工具 | 所有访客 |

## 用户角色

| 角色 | 说明 | 创建工具 | 发布工具 | 审核工具 | 管理用户 |
|------|------|---------|---------|---------|---------|
| **Owner** | 平台所有者 | ✅ 直接发布 | ✅ | ✅ | ✅ |
| **Member** | 团队成员 | ❌ | ❌ | ❌ | ❌ |
| **Contributor** | 贡献者 | ✅ 需审核 | ❌ | ❌ | ❌ |
| **Public** | 访客 | ❌ | ❌ | ❌ | ❌ |

| Member | ❌ | ✅ | ✅ |
| Contributor | ❌ | ❌ | ✅ |

同 canView

| Owner | ✅ | ✅ |
| Member | ❌ | ❌ |
| Contributor | ❌ | ❌ |
| Public | ❌ | ❌ |

| 角色 | 自己创建的工具 | 其他人的工具 |
|------|--------------|-------------|
| Owner | ✅ | ✅ |
| Member | ❌ | ❌ |
| Contributor | ❌ | ❌ |

| 角色 | 直接发布 | 提交审核 |
|------|---------|---------|

| Member | ❌ | ❌ |
| Contributor | ❌ | ✅ |
| Public | ❌ | ❌ |

## 工具状态流转

```
                    ┌──────────┐
                    │  draft  │
                    └────┬─────┘
                         │ contributor 提交
                         ▼
┌──────────┐      ┌──────────┐      ┌──────────┐
│deprecated│ ◄─── │published│ ───► │  review  │
└──────────┘      └──────────┘      └────┬─────┘
                         ▲               │
                         │               │ owner 审核
                         │               ▼
                         │         ┌──────────┐
                         └─────────│ approved │
                                   └──────────┘
                                        │
                                        │ rejected → 返回 draft
```

## API 权限控制

### 工具操作

| 操作 | 权限要求 |
|------|---------|
| GET /registry | 公开，无需认证 |
| GET /tools | 需认证，返回用户可访问的工具 |
| POST /tools | 需认证 |
| PUT /tools/:id | 需认证，且是工具 owner |
| DELETE /tools/:id | 需认证，且是工具 owner |
| POST /tools/:id/review | 需认证，且是工具 owner |

### 团队操作

| 操作 | 权限要求 |
|------|---------|
| GET /teams | 需认证，返回用户所在的团队 |
| POST /teams | 需认证 |
| GET /teams/:id | 需认证，且是团队成员 |
| POST /teams/:id/members | 需认证，且是 team owner |
| DELETE /teams/:id/members/:userId | 需认证，且是 team owner |

## 核心原则

1. **所有权不可转移** - 工具的 owner 永远是平台 owner
2. **审核权在 owner** - 社区工具必须经过 owner 审核才能公开
3. **贡献者有署名** - 贡献者的名字会记录在工具的 contributors 中
4. **可追溯** - 所有操作都有记录
